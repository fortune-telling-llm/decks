# Original Etteilla Tarot — Le Jeu de Thot (1791) — Cards

This file defines the historical **78-card** sequence documented for Original Etteilla Tarot — Le Jeu de Thot (1791).

The table uses stable repository sequence numbers while preserving historical card numbers, titles, ranks, and edition-specific exceptions inside the card name or description. Short descriptions identify the card’s primary visual or structural role; they are not substitutes for future image-led card files.

Unlike a Marseille or Waite–Smith sequence, the historical numbering runs through the entire pack: creation and moral subjects occupy `1–21`; the four suits occupy `22–77`; and Folly or the Alchemist is `78`. Suit blocks run Wands, Cups, Swords, and Coins, each from King down to Ace.
