# Oswald Wirth — Les 22 Arcanes du Tarot Kabbalistique (1889) — Cards

This file defines the historical **22-card** sequence documented for Oswald Wirth — Les 22 Arcanes du Tarot Kabbalistique (1889).

The table uses stable repository sequence numbers while preserving historical card numbers, titles, ranks, and edition-specific exceptions inside the card name or description. Short descriptions identify the card’s primary visual or structural role; they are not substitutes for future image-led card files.

This entry documents the original 22-atout hand-colored lithographic set, not later commercial 78-card expansions. French titles, Hebrew letters, occult additions, and exact plate details must be verified from the 1889 cards.
